# Minecraft Dino Game 🦖🔊

A reimagining of the classic Google Chrome offline Dinosaur game, completely overhauled with authentic **Minecraft: Java Edition** sound effects. Experience the thrill of dodging obstacles while immersed in the audio landscape of your favorite block game.

### 🎮 Features
* **Nostalgic Audio:** Every jump, score milestone, and game over screen triggers iconic Minecraft Java sounds (think jumping *thuds*, experience orb *dings*, and classic player *damage* sounds).
* **Classic Gameplay:** Simple, addictive, and fast-paced endless runner mechanics.
* **Pixel-Perfect Aesthetic:** Clean visuals paired with crisp, retro audio.
